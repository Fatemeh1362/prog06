Workflow Design
Breakdown of the Workflow

preprocess_data:
The starting point of the workflow.
Preprocesses the raw dataset (diseaseDk_PCR_Hanze_WP2.xlsx) by imputing missing values, encoding categorical features, and splitting it into training (train_data.csv) and testing (test_data.csv) datasets.
Outputs are used as inputs for all subsequent steps.

train_ensemble and tune_ensemble:
train_ensemble: Trains the base ensemble model and generates ensemble_model.pkl.

tune_ensemble: Optimizes the ensemble model hyperparameters, creating the best model (ensemble_best_model.pkl) and storing tuning results in ensemble_tuning_results.csv.
tune_random_forest:

Optimizes the Random Forest model hyperparameters, creating the best model (RF_best_model.pkl) and storing tuning results in RF_tuning_results.csv.
Depends on both the preprocessed training dataset (train_data.csv) and the previously generated base model (random_forest_model.pkl).
evaluate_random_forest and evaluate_ensemble:

evaluate_random_forest: Evaluates the tuned Random Forest model on the test dataset, generating evaluation metrics (random_forest_results.txt).
evaluate_ensemble: Evaluates the tuned ensemble model on the test dataset, generating evaluation metrics (ensemble_results.txt).
plot_hyperparameter_results:

Creates a plot visualizing the hyperparameter tuning results for the ensemble model (hyperparameter_plot.png).
Uses ensemble_tuning_results.csv as input.

generate_comparison_plot:
Compares the evaluation metrics of the Random Forest and Ensemble models.
Creates a comparison plot (comparison_plot.png) based on random_forest_results.txt and ensemble_results.txt.

create_report:
Aggregates evaluation metrics and generates a final summary report (final_report.csv).

all:
Ensures all required artifacts (models, metrics, plots, and reports) are generated as part of the complete workflow.


Logic of the Workflow
Sequential Execution: The workflow begins with preprocess_data, which serves as the foundation for all other steps.
Parallelization: Independent steps, such as training the ensemble model and tuning the Random Forest model, run in parallel, optimizing computational resource usage.

Dependencies:
Model evaluation (evaluate_random_forest, evaluate_ensemble) depends on their respective tuned models.
Visualization steps (plot_hyperparameter_results, generate_comparison_plot) depend on earlier evaluation and tuning steps.
The final report generation (create_report) aggregates results from evaluations and visualizations.
